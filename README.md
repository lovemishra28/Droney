This is a Next.js project bootstrapped with `create-next-app`.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open the URL configured in `NEXT_PUBLIC_APP_URL` with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses `next/font` to automatically optimize and load Geist.

## Learn More

Refer to the official Next.js documentation for framework guidance.

## Deploy

Configure the environment variables in `.env.production` before deploying.
